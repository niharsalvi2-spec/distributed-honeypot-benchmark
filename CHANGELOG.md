# Changelog

All notable changes to this project will be documented in this file.

## [v1.0.0] - 2026-08-15
### Added
- Initial benchmark suite architecture and repository structure.
- Comprehensive documentation across 10 subject domains (`docs/00` to `docs/10`).
- Baselines integration specifications for Cowrie, OpenCanary, T-Pot, Dionaea, MHN, Conpot, and Honeytrap.
- 10 experimental protocols (E01 to E10) covering functional validation, correlation, ordering, fault tolerance, and scalability.
- Canonical event schema and parser normalizers for all 7 honeypot engines.
- Lamport Clock and Vector Clock distributed event-ordering modules.
- Controlled attack campaign generator with ground-truth verification.
- Benchmark specifications workbook registry (.xlsx) and validation test suites.
